# CrimsonCombat One-Drop

Run `Installer/CrimsonCombat_OneDrop_Installer.luau` once in Roblox Studio's Command Bar.

It installs:
- `ServerScriptService/CrimsonCombatServer`
- `StarterPlayer/StarterPlayerScripts/CrimsonCombatClient`

The runtime remains split because Roblox requires server authority for multiplayer damage and client execution for GUI/input.
